# Credit Risk Scoring and Early Default Warning System

Production-style AI/ML project scaffold for credit risk scoring and early default warning using the Home Credit Default Risk dataset.

## Project Structure

```text
data/
  raw/                  # Original Home Credit CSV files; do not modify manually
  processed/            # Cleaned or transformed data generated by Python code
notebooks/
  01_eda.ipynb
src/
  config.py
  validate_data.py
  data_preprocessing.py
  feature_engineering.py
  train_model.py
  evaluate_model.py
  predict.py
models/
api/
  app.py
dashboard/
  streamlit_app.py
reports/
  figures/
```

## Data Handling Rules

- Do not manually clean or modify CSV files.
- Keep all original raw files unchanged in `data/raw`.
- Perform all data cleaning and transformation through Python code.
- Save cleaned or transformed datasets only in `data/processed`.
- Model training is intentionally not implemented yet.

## Required Raw Files

Place the original Home Credit Default Risk CSV files in `data/raw`:

- `application_train.csv`
- `application_test.csv`
- `bureau.csv`
- `bureau_balance.csv`
- `previous_application.csv`
- `POS_CASH_balance.csv`
- `credit_card_balance.csv`
- `installments_payments.csv`
- `HomeCredit_columns_description.csv`
- `sample_submission.csv`

## Validate Raw Data

Run the validation script from the project root:

```bash
python src/validate_data.py
```

The script checks required CSV availability, prints file sizes, confirms each CSV can be read from a five-row sample, and reports `application_train.csv` shape plus `TARGET` distribution.
